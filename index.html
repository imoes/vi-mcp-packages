vi-mcp package repository

Signed apt, dnf and pacman repositories for vi-mcp, so a server gets new versions with its normal updates. The same packages are attached to every GitHub release.

Signing key (OpenPGP, Ed25519): 4598 3154 14EB F86C ABD3 22D9 730B 75BF AC30 36B7 — vi-mcp-repo.asc. Compare the fingerprint with the one in the README of the code repository before you trust it.

In one line

curl -fsSL https://imoes.github.io/vi-mcp-packages/setup.sh | sudo sh

Adds the repository — key and source — on apt, dnf and pacman systems, installs nothing else (read it first). Then sudo apt install vi-mcp, sudo dnf install vi-mcp or sudo pacman -Syu vi-mcp. The same by hand:

Debian 12+, Ubuntu 24.04+

sudo curl -fsSLo /usr/share/keyrings/vi-mcp.gpg https://imoes.github.io/vi-mcp-packages/vi-mcp-repo.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/vi-mcp.sources https://imoes.github.io/vi-mcp-packages/vi-mcp.sources
sudo apt update && sudo apt install vi-mcp        # later: sudo apt upgrade

Fedora, AlmaLinux/RHEL 10 (with EPEL)

sudo curl -fsSLo /etc/yum.repos.d/vi-mcp.repo https://imoes.github.io/vi-mcp-packages/vi-mcp.repo
sudo dnf install vi-mcp                              # later: sudo dnf upgrade

dnf asks once to import the key; check that its fingerprint is the one above.

Arch Linux, CachyOS

curl -fsSLo /tmp/vi-mcp-repo.asc https://imoes.github.io/vi-mcp-packages/vi-mcp-repo.asc && sudo pacman-key --add /tmp/vi-mcp-repo.asc
sudo pacman-key --lsign-key 4598315414EBF86CABD322D9730B75BFAC3036B7
curl -fsSL https://imoes.github.io/vi-mcp-packages/vi-mcp.pacman.conf | sudo tee -a /etc/pacman.conf
sudo pacman -Syu vi-mcp                              # later: sudo pacman -Syu
sudo systemctl enable --now vi-mcp.service

Packages and the database are signed (SigLevel = Required); the key is trusted only for what you sign locally.
