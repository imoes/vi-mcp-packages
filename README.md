# vi-mcp packages

Signed apt and dnf repositories for [vi-mcp](https://github.com/imoes/vi-mcp), served by GitHub Pages:
**https://imoes.github.io/vi-mcp-packages/** — how to add them is on that page and in the vi-mcp README.

Built by `deploy/publish-repo.sh` of the code repository at every release; nothing here is edited by hand.
